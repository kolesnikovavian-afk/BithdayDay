# 🟢 Зелёный Биом — Android-приложение (PWA)

Квест на день рождения. Приложение открывается на телефоне, сканирует QR, играет музыку, показывает задания.

---

## 📋 Что умеет

- **Сканирует QR** — каждое сканирование = шаг квеста
- **Играет музыку** из Яндекс.Музыки (открывает трек в приложении)
- **Ведёт трекер изумрудов** — 4 слота, прогресс сохраняется
- **Показывает задания** на главном экране
- **Таймер танца** — 10 секунд
- **Рандомайзер пожеланий** — 24 тёплых сообщения с Дракончиком, ящеркой, Фенрисом, ChamomileRin, гитарой и туризмом
- **Кнопка ПОВЫСИТЬ ХП** — открывает подсказку где следующий конверт

## 🗺 Маршрут квеста

```

СПАЛЬНЯ  →  ВАННАЯ  →  КУХНЯ   →  ОФИС      →  КНИГА    →  ПОДАРОК
(шкаф)      (таз)      (стол)     (домик)     (полка)     (диван)
2П         5О         1Р         0А

```

**Дата:** 25.10 → изумруды **2-5-1-0**
**Буквы:** П-О-Р-А → соберёшь слово

## 🚀 Как захостить

### Вариант 1. Vercel (рекомендую)

1. **https://vercel.com/new** → Sign up через Google.
2. Перетащи папку `quest-app` в окно.
3. **Deploy** → получишь `https://quest-app-xxx.vercel.app`.
4. Отправь ссылку девушке.

### Вариант 2. Netlify Drop

1. **https://app.netlify.com/drop**
2. Перетащи папку `quest-app` (не ZIP — папку!).

### Вариант 3. GitHub Pages

⚠️ Нужен **публичный** репозиторий. Для приватных GitHub Pages бесплатно не работает.

1. Settings → General → Change visibility → Make public.
2. Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)` → Save.
3. `https://твой-ник.github.io/имя-репо/`

**Важно:** камера работает только на **HTTPS**. Все варианты дают HTTPS.

## 🎵 Настройка музыки

Открой `app.js`. Наверху:

```javascript
const MUSIC = {
  wardrobe: 'https://music.yandex.ru/album/39791459/track/146310605', // C418 — Subwoofer Lullaby
  kitchen:  'https://music.yandex.ru/album/39791459/track/146310631', // C418 — Sweden
  office:   'https://music.yandex.ru/album/3347333/track/28038563',   // Нейромонах Феофан — Пляс
  book:     'https://music.yandex.ru/album/36104524/track/137904480'  // финальная
};
```

**Как поменять:** открой трек в Яндекс.Музыке → ⋯ → Поделиться → Скопировать ссылку → вставь без хвоста `?utm...`.

## 📩 Что распечатать

Открой в браузере и распечатай:

1. **`emeralds.html`** → 4 изумруда (2П, 5О, 1Р, 0А) — вырежи
2. **`envelopes.html`** → тексты для 7 конвертов — разрежь, сложи в зелёные конверты
3. **`qr-generator.html`** → 8 QR-кодов → нажми «Распечатать всё» → разрежь → расклей

**Куда клеить QR:**

- `WARDROBE` → в конверт в шкафу
- `BATH_DANCE` → на дно таза
- `KITCHEN_MUSIC` → на дверь кухни
- `KITCHEN_RECIPE` → в конверт на кухонном столе
- `OFFICE_MUSIC` → на дверь офиса
- `CAT_HOUSE` → в конверт внутри домика кота Марса
- `BOOK_SONG` → в конверт в книге
- `FINAL` → в последний конверт рядом с подарком

## 📝 Полный сценарий квеста

### 1. Утро

Девушка открывает ссылку на приложение. Видит:

> *«Доброе утро, дракончик. Ты заспавнилась в новом мире. Правила: 4 биома, 4 изумруда, один подарок. Готова начать?»*

Нажимает **Начать**.

### 2. Спальня

На главном экране — загадка:

> *Где рубашки спят в тишине, / где мой свитер дышит в темноте, / на моей стороне — / там тебя ждёт первый камень.*

Идёт к шкафу, находит конверт с QR. Сканирует → играет **Subwoofer Lullaby** + отмечается **изумруд 2П**.

### 3. Ванная

Идёт в ванную. На комоде — конверт с текстом «Ищи таз». На дне таза — QR. Сканирует → 10-секундный таймер танца. После танца — следующие указания + отмечается **изумруд 5О**.

### 4. Кухня

QR на двери → музыка **Sweden**. На столе — конверт. Внутри: рецепт настоя викинга + QR. Сканирует QR → открывается рецепт + отмечается **изумруд 1Р**. Внизу — кнопка **ПОВЫСИТЬ ХП** → показывает подсказку куда идти (в офис, но с загадкой).

### 5. Офис (Древняя Русь)

QR на двери → **Нейромонах Феофан — Пляс**. На столе — конверт с загадкой про вонючее чудовище. Идёт к домику кота Марса, находит конверт с изумрудом. Сканирует → отмечается **изумруд 0А** + указание идти к книге: *«Где око видит, что вы начали вместе быстро, но до сих пор не закончили.»*

### 6. Книга

Находит «Властелина колец» на полке. Внутри — конверт с QR. Сканирует → играет финальная песня + показывается шифр: выложить изумруды в порядке 2-5-1-0, отнять цифры от букв, получить слово → **ПЛЕД** (или другое финальное слово, по задумке).

### 7. Финал

Рядом с подарком — последний конверт: **«Я люблю тебя! С днём рождения, Дракончик!»**

---

## ⚠️ Про шифр в финале

В файле `app.js` в действии `BOOK_SONG` есть текст шифра. По умолчанию: изумруды 2-5-1-0 → буквы П-О-Р-А. Если хочешь другой шифр — поменяй буквы в массиве `EMERALDS` наверху `app.js` и текст в `BOOK_SONG`.

## 🆘 Если что-то не работает

**Камера не открывается** → нужен HTTPS. Локальный файл не подойдёт.
**QR не сканируется** → проверь свет, чёткость QR.
**Кнопка «Слушать» не открывает Яндекс.Музыку** → на телефоне должно быть установлено приложение Яндекс.Музыки, или откроется в браузере.
**Всё сломалось** → кнопка «📋 Список QR» на главном экране — ручной запуск действий.
