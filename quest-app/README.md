# 🟢 Зелёный Биом — Android-приложение (PWA)

Приложение для квеста: сканирует QR, играет музыку, показывает рецепты и пожелания.

**Формат:** PWA (Progressive Web App). Работает на Android в Chrome. Можно "установить" на домашний экран и оно будет выглядеть как обычное приложение.

---

## 📱 Что умеет

- 📷 **Сканировать QR** через камеру телефона
- 🎵 **Играть музыку** — по QR включается YouTube-трек
- 🍯 **Показывать рецепт** — по QR открывается медовуха
- 💎 **Отслеживать изумруды** — прогресс сохраняется
- 🎁 **Генерировать пожелания** — кнопка "Пожелание" показывает случайное тёплое сообщение
- ⏱ **Таймер танца** — 10 секунд с отсчётом
- 🔐 **Шифры** — отображает загадки

## 🚀 Как установить

### Вариант 1. Netlify Drop (самый простой, 2 минуты)

1. Открой **https://app.netlify.com/drop**
2. Перетащи **всю папку `quest-app`** в окно браузера
3. Через 10–20 секунд получишь ссылку типа `https://random-name.netlify.app`
4. Отправь эту ссылку девушке (или открой у неё на телефоне)
5. В Chrome: **⋮ → Установить приложение** (или "Добавить на главный экран")

### Вариант 2. GitHub Pages

1. Создай репозиторий на GitHub
2. Загрузи файлы `quest-app/`
3. Settings → Pages → Source: main branch → Save
4. Через минуту откроется ссылка `https://username.github.io/repo/`

### Вариант 3. Vercel

1. Открой **https://vercel.com/new**
2. Перетащи папку
3. Получи ссылку

**Важно:** камера (для QR-сканирования) работает только на **HTTPS**. Все три варианта дают HTTPS автоматически. Локальный файл (`file://`) — не сработает.

## 🎵 Настройка музыки (обязательно!)

Открой `app.js`. В самом верху найди блок:

```javascript
const MUSIC = {
  baza:             'REPLACE_BAZA_VIDEO_ID',
  sweden:           'REPLACE_SWEDEN_VIDEO_ID',
  ariaMath:         'REPLACE_ARIAMATH_VIDEO_ID',
  subwooferLullaby: 'REPLACE_SUBWOOFER_VIDEO_ID'
};
```

Замени `REPLACE_...` на настоящие YouTube ID.

### Как найти YouTube ID

1. Открой нужный трек на YouTube, например:
`https://www.youtube.com/watch?v=**dQw4w9WgXcQ**`
ID = то, что после `v=` → **`dQw4w9WgXcQ`**
2. Вставь его вместо placeholder'а.

### Нужные треки

| Ключ ↕▾ | Что искать ↕▾ |
|---|---|
| −`baza` | Sqwoz Bab — BAZA |
| `sweden` | C418 — Sweden |
| `ariaMath` | C418 — Aria Math |
| `subwooferLullaby` | C418 — Subwoofer Lullaby |

## 🔳 Как сгенерировать QR-коды

1. Открой **`qr-generator.html`** в браузере (двойной клик по файлу).
2. Увидишь 8 готовых QR-кодов.
3. Нажми **🖨 Распечатать всё** — распечатаются все QR на одном листе.
4. Разрежь и расклей:

| QR ↕▾ | Куда клеить ↕▾ |
|---|---|
| −`BATH_MUSIC` | На дверь ванной |
| `BATH_DANCE` | На дно таза (двусторонним скотчем) |
| `KITCHEN_MUSIC` | На дверь кухни |
| `KITCHEN_RECIPE` | На стол / на лист с рецептом |
| `OFFICE_MUSIC` | На дверь офиса |
| `OFFICE_HINT` | В домик кота Марса |
| `START` / `FINAL` | Опционально |
⚙

**Проверь все QR своим телефоном до квеста!**

## 🎮 Как это работает

1. Девушка открывает приложение (ссылка / иконка на домашнем экране).
2. Видит: 4 слота под изумруды, все пустые.
3. Нажимает **📷 Сканировать QR** → наводит на код.
4. Приложение:

- Включает музыку (если это музыкальный QR)
- Запускает таймер (если танец)
- Показывает рецепт (если кухня)
- Показывает подсказку
- Отмечает изумруд автоматически
5. В любой момент можно нажать **🎁 Пожелание** — покажет случайное тёплое сообщение.
6. В конце — все изумруды собраны.

## 🛠 Дополнительно

### Изменить пожелания

Открой `app.js`, найди массив `WISHES` — там ~20 сообщений. Меняй под себя, добавляй свои.

### Изменить текст действий

Открой `app.js`, найди `QR_ACTIONS` — там все тексты, которые видит она. Можешь переписать под себя.

### Сбросить прогресс

На главном экране — кнопка "Сбросить прогресс" (внизу).

### Ручной режим

Кнопка "📋 Список QR" на главном — открывает список всех QR для ручного запуска (удобно тестировать без камеры).

## 🆘 Если что-то не работает

**Камера не открывается**
→ Проверь, что ссылка начинается с `https://` (не `file://`).
→ Разреши доступ к камере в настройках Chrome.
→ Попробуй Chrome, а не встроенный браузер (например, в Telegram).

**Музыка не играет**
→ Проверь, что YouTube ID правильный.
→ Убедись, что интернет есть.
→ Если видео заблокировано в регионе — YouTube покажет ошибку, попробуй другое.

**QR не сканируется**
→ Убедись, что QR чёткий и не размытый.
→ Не сгибай бумагу.
→ Проверь освещение (не должно быть бликов на QR).

**Всё сломалось — что делать?**
→ На главном экране кнопка "📋 Список QR" — открывает список всех действий вручную.
→ Или скажи ей код голосом: "нажми в списке `BATH_MUSIC`".
